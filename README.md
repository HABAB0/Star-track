#  Star-track

**[Играть (Live Demo)](https://habab0.github.io/Star-track/)**

**Star-track** — это интерактивное веб-приложение (браузерная игра), разработанное с использованием современного стека технологий на базе экосистемы Vue. Проект демонстрирует навыки компонентного подхода, управления состоянием приложения и строгой типизации в реальных условиях.

---

##  Основные возможности

- **Управление состоянием игры:** Реализована логика переключения между экранами (меню, игровой процесс, пауза, экран завершения/"death screen").
- **Компонентная архитектура:** Интерфейс разбит на переиспользуемые, независимые компоненты для упрощения поддержки и тестирования.
- **Строгая типизация:** Активное использование TypeScript для пропсов, событий и внутренних состояний, что снижает количество runtime-ошибок.
- **Адаптивность и стилизация:** Чистый CSS/SCSS без тяжелых библиотек, что обеспечивает высокую скорость загрузки и рендеринга.
- **Готовность к продакшену:** Настроен линтинг (ESLint) и форматирование (Prettier) для поддержания единого стиля кода.

##  Структура проекта

Проект использует стандартную и интуитивно понятную структуру Nuxt 3:

```text
├── assets/          # Глобальные стили, шрифты и изображения
├── components/      # Переиспользуемые UI-компоненты (кнопки, модальные окна, игровые элементы)
├── composables/     # Переиспользуемая логика состояния (хуки, управляющие игрой)
├── pages/           # Маршруты приложения (главная страница, игровое поле)
├── public/          # Статические файлы (favicon, robots.txt)
├── app.vue          # Корневой компонент приложения
├── nuxt.config.ts   # Конфигурация Nuxt
├── package.json     # Зависимости и скрипты
└── tsconfig.json    # Настройки TypeScript
```

##  Установка и локальный запуск

Для запуска проекта на вашем локальном компьютере выполните следующие шаги:

### 1. Клонирование репозитория
```bash
git clone https://github.com/HABAB0/Star-track.git
cd Star-track
```

### 2. Установка зависимостей
Вы можете использовать любой удобный вам пакетный менеджер:
```bash
npm install
# или
pnpm install
# или
yarn install
# или
bun install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
После запуска приложение будет доступно по адресу: **[http://localhost:3000](http://localhost:3000)**

### 4. Сборка для продакшена
```bash
# Сборка оптимизированной версии
npm run build

# Локальный предпросмотр собранной версии
npm run preview
```

##  Как пользоваться

1. При запуске отображается **Главное меню** с кнопкой начала игры.
2. После старта активируется **Игровой цикл** — основная механика приложения.
3. Во время игры доступна функция **Паузы** (останавливает логику и показывает оверлей).
4. При наступлении условия проигрыша отображается **Экран завершения (Death Screen)** с возможностью перезапуска игры.

### Краткая схема взаимодействия:
```text
[Главное меню] → [Игровой процесс] ⇄ [Пауза]
                       ↓
               [Death Screen] → [Рестарт]
```
